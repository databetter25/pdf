# 확률변수 실험실 (prob_dist)

확률변수, 확률질량함수·확률밀도함수, 누적분포함수를 시뮬레이션으로 직관적으로 익히는 교육용 정적 웹사이트입니다.

| 모듈 | 내용 | PRD |
|---|---|---|
| 모듈 1 히스토그램에서 분포로 | 세로축(도수·상대도수·밀도), n과 Δx의 두 극한, PDF·PMF | `PRD_prob_dist.md` |
| 모듈 2 누적분포함수 | ECDF의 수렴, 넓이와 기울기, 점프와 질량, 분위수, 역변환 표본추출, 혼합분포 | `PRD_module2_cdf.md` |
| 모듈 3 확률변수란 무엇인가 | 표본공간, 결과에 수 붙이기, 역상과 유도 분포, 연속 표본공간의 넓이, 확률변수의 함수 | `PRD_module3_random_variable.md` |
| 모듈 4 측도론과 확률분포 | 푸시포워드, 라돈–니코딤, 칸토어 분포, 르베그 분해, 층 케이크, MCT·DCT, 수렴의 종류, 강한 대수의 법칙, 가능도, 중요도 표본추출, 조건부 기댓값, 라오–블랙웰 | `PRD_module4_measure.md` |

## 실행

빌드 과정이 없습니다.

- **그냥 열기**: `index.html`을 브라우저로 열면 됩니다. ES 모듈·fetch·Web Worker를 쓰지 않아 `file://`에서도 동작합니다.
- **로컬 서버**: `python -m http.server 8000` 후 <http://localhost:8000>
- **GitHub Pages**: 저장소 루트에 이 폴더 내용을 올리고 Pages를 켜면 됩니다.

D3와 KaTeX는 `vendor/`에 포함되어 있어 인터넷 없이 동작합니다. 글꼴(Gowun Batang, IBM Plex Sans KR)만 Google Fonts에서 받으며, 연결이 없으면 시스템 글꼴로 바뀝니다.

### PRD와 다르게 정한 점

- **공통 코드 분리**: 모듈 2 PRD 7.1은 `js/core/`에 셸·상태·조작 패널을 모두 분리하도록 했지만, 머리글·단계 카드·발표 모드 같은 셸(`shell.js`)만 공통으로 두었습니다. 상태와 조작 패널은 모듈마다 성격이 달라 각 `app.js`에 두었고, 모듈 1은 기존 `js/app.js`가 셸을 쓰도록만 바꿨습니다(모듈 1 회귀 테스트 통과).
- **Web Worker 대신 메인 스레드 생성**: `file://`에서 바로 열리게 하려고 Worker를 쓰지 않았습니다. n = 1,000,000 생성은 분포에 따라 20~220ms입니다.
- **열린 질문의 기본값**: 모듈 번호는 그대로 두고 홈과 교수자 안내에 “처음이라면 모듈 3부터”를 안내했습니다. 모듈 2의 기본 분포는 지수분포(λ = 1)입니다. 동전 “처음 앞면”은 앞면이 없으면 0으로 두고, 값이 정의되지 않는 경우는 자유 실험실의 사용자 정의 식(예: `ln(a - 1)`)으로 보여 줍니다.
- **모듈 3 정사각형 점**: 최대 100,000개, 유한 표본공간의 반복 실험은 최대 1,000,000번입니다. 표본공간을 바꾸면 반복 실험은 처음부터 시작합니다.
- **포아송 표본추출**은 PTRS 대신 누적확률표 + 이진 탐색 역변환, **기하분포**는 ‘첫 성공까지의 시행 횟수’(x = 1, 2, …)로 정의했습니다.
- 학습 노트의 역사 부분에는 모듈 1 PRD 부록 B에서 확인이 필요하다고 표시한 두 주장을 넣지 않았습니다.
- **모듈 4 그림**: PRD 9장은 `cdfchart.js`·`omegaview.js` 재사용을 적었지만, 측도론 장면은 축 하나에 점 질량·밀도·특이 성분을 함께 그려야 해서 `m4lib.js`의 가벼운 그림 틀(`plot`)과 `module4/ui.js`로 새로 그렸습니다. A4는 PRD의 표본 히스토그램에 더해, 합친 CDF 위의 ECDF와 KS 거리(점 질량의 동점을 묶어 계산)로도 표본을 확인합니다. 특이 성분은 히스토그램만으로는 알아보기 어렵기 때문입니다.
